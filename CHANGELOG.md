- First standalone installable package with a public command line and optional training dependencies.
- Migrated the reviewed WP05A numerical profile and 78 byte-identical WP04A inference states, with separate provenance.
- Added NumPy-only selective metrics, deterministic label-free tie breaking, safe data extraction, independent table audit, and shared-denominator direction diagnostics.

- Fixed the first integration audit's underscore-column compatibility error; preserved its failure record.
- Local candidate only. No PyPI/GitHub release, remote CI run, external adoption, archive DOI, or journal submission is claimed.
